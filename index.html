🔒 ระบบความปลอดภัย & การติดตั้งบน GitHub

1. ไม่เก็บ Cache และไม่ส่งข้อมูลออกนอกเครื่อง 100%

รูปภาพของคุณจะถูกอ่านเข้าสู่หน่วยความจำชั่วคราว (RAM) ของเบราว์เซอร์เท่านั้น ไม่มีการอัปโหลดไปยังเซิร์ฟเวอร์ใดๆ และไม่มีการบันทึกลง LocalStorage หรือ IndexedDB

2. คงความละเอียดต้นฉบับสูงสุด (Full-Resolution Pipeline)

ระบบใช้ AI วิเคราะห์แยกวัตถุและนำ Alpha Mask ความละเอียดสูงมาผสานกลับเข้ากับพิกเซลต้นฉบับขนาดจริง 100% ทำให้ภาพคมชัดไม่แตกแม้ซูมดูใกล้ๆ

3. วิธีอัปโหลดขึ้น GitHub Pages (ใช้งานฟรีตลอดชีพ)

  1. สร้าง Repository ใหม่บน GitHub (ตั้งชื่อ เช่น remove-bg)
  2. อัปโหลดไฟล์นี้โดยตั้งชื่อว่า index.html
  3. ไปที่ Settings > Pages เลือก Branch เป็น main แล้วกด Save
  4. เปิดลิงก์ผ่านมือถือและกด "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้เป็นแอปได้ทันที!
